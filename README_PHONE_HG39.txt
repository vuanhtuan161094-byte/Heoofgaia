1. Giải nén ZIP vào bộ nhớ máy.

- Chiến trường: chạm đội quân hoặc ô lục giác, sau đó dùng bảng lệnh bên phải.
- Lưu: game tự lưu trong Chrome trên điện thoại này. Dùng nút Sao lưu để xuất file dự phòng.
