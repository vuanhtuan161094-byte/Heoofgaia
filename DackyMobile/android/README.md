# Android handoff

Android SDK, Gradle và Capacitor chưa có trong execution environment hiện tại. capacitor.config.json khai báo app id và thư mục web build, nhưng đây chưa phải một project Android native và không có APK giả lập. Làm theo docs/BUILD_GUIDE.md sau khi cài toolchain; không thêm khóa hoặc dữ liệu cục bộ vào Git.
